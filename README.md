# STM32 Fan Controller

A simple embedded fan controller built using an STM32F103C8T6
microcontroller.

## Project Overview

The goal of this project is to build a temperature-controlled DC
fan with manual and automatic operating modes.

## Planned Features

- OFF / ON / AUTO operating modes
- Manual fan-speed adjustment using a potentiometer
- Automatic fan-speed control based on temperature
- Temperature sensing

## Hardware

- STM32F103C8T6 (Blue Pill)
- DC fan
- Temperature sensor
- Potentiometer
- 3-position selector switch
- ST-Link programmer

## Development

This project is being developed using:

- C/C++
- PlatformIO
- STM32F103C8T6
- Direct register manipulation
- Git/GitHub
